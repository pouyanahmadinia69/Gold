زرین | اپلیکیشن مدیریت طلافروشی (نسخه اولیه)

فایل‌ها را همگی در ریشه یک Repository جدید GitHub قرار دهید:
- index.html
- styles.css
- app.js
- manifest.json
- sw.js
- goldfox-logo.png
- icon-192.png
- icon-512.png

فعال‌سازی GitHub Pages:
1) وارد Settings مخزن شوید.
2) از بخش Pages، گزینه Deploy from a branch را انتخاب کنید.
3) Branch را روی main و Folder را روی /(root) بگذارید و Save کنید.
4) پس از انتشار، لینک Pages را با Safari یا Chrome باز کنید.
5) در iPhone: Share > Add to Home Screen. در Android: منوی مرورگر > Install app.

نکات مهم:
- داده‌ها فعلاً در حافظه محلی همان مرورگر (localStorage) ذخیره می‌شوند؛ بین دستگاه‌ها همگام نیستند.
- فایل پشتیبان JSON از طریق دانلود مرورگر ذخیره می‌شود؛ محتویات آن در برنامه نمایش داده نمی‌شود.
- بازیابی، اطلاعات فعلی را با نسخه پشتیبان جایگزین می‌کند.
- این نسخه MVP اولیه است و هنوز دفتر حساب طلایی، بدهکاری/طلبکاری، اجرت/سود، فاکتور چاپی، چندکاربره و همگام‌سازی ابری ندارد.
- برای استفاده واقعی تجاری، قبل از ورود اطلاعات حساس، باید نسخه بعدی با دیتابیس امن و کنترل دسترسی پیاده‌سازی و تست شود.
